# \# Bhumi Patna Portal

# 

# A minimalist, high-performance web portal for managing the Bhumi Patna chapter. This platform facilitates task management, resource sharing, and performance tracking for Admins, Interns, and Campus Ambassadors.

# 

# \## Features

# 

# \*   \*\*Role-Based Access Control:\*\* Secure routing for Admins, Interns, and Campus Ambassadors.

# \*   \*\*Minimalist UI:\*\* A clean, distraction-free interface prioritizing data visibility and ease of use.

# \*   \*\*Admin Control Panel:\*\* Complete CRUD (Create, Read, Update, Delete) capabilities for:

# &#x20;   \*   Users (Admins, Interns, Campus Ambassadors)

# &#x20;   \*   Missions (Tasks)

# &#x20;   \*   Resources

# \*   \*\*Leaderboard System:\*\* Automated tracking of points and impact generated by volunteers.

# \*   \*\*Supabase Backend:\*\* Fully migrated from SQLite to Supabase (PostgreSQL) for scalable cloud data management.

# 

# \## Tech Stack

# 

# \*   \*\*Backend:\*\* Python 3.11.9, Flask

# \*   \*\*Database:\*\* Supabase (PostgreSQL)

# \*   \*\*Frontend:\*\* HTML5, CSS3 (Minimalist Custom Styling), Jinja2 Templating

# \*   \*\*Hosting:\*\* Render.com
