# Bhumi Patna Portal

A minimalist, high-performance web portal for managing the Bhumi Patna chapter. This platform facilitates task management, resource sharing, and performance tracking for Admins, Interns, and Campus Ambassadors.

## Features

*   **Role-Based Access Control:** Secure routing for Admins, Interns, and Campus Ambassadors based on PostgreSQL data.
*   **Minimalist UI:** A clean, distraction-free interface prioritizing data visibility and ease of use.
*   **Admin Control Panel:** Management capabilities for:
    *   Interns & Campus Ambassadors
    *   Missions (Tasks)
    *   Resources
*   **Leaderboard System:** Tracking of points and impact generated by volunteers.
*   **Supabase Backend:** Fully migrated from SQLite to Supabase (PostgreSQL) for scalable cloud data management.

## Tech Stack

*   **Backend:** Python 3.11, Flask
*   **Database:** Supabase (PostgreSQL)
*   **Frontend:** HTML5, CSS3 (Minimalist Custom Styling), Jinja2
*   **Hosting:** Render.com

## Environment Variables Needed (Render / `.env`)
*   `SECRET_KEY`
*   `SUPABASE_URL`
*   `SUPABASE_KEY`
